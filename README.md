# 赛尔档案馆 · SEER ARCHIVE

赛尔档案馆是一个蓝黑黄机能科技风的图片与视频资料馆界面演示。项目用于展示资料分类、主题编辑、开场动画、BGM 控制、图片兜底和【壁纸插画】3D 浏览。

## 在线演示

GitHub Pages：<https://seerlink-3599.github.io/SeerArchivesDemo2/>

静态入口位于 `docs/`，根目录 `index.html` 会自动跳转到该入口。静态版本只使用仓库内置素材，完整素材索引、主题持久保存和真实上传仍由本地版提供。

## 项目结构

```text
docs/
├─ index.html              # 赛尔档案馆演示入口
├─ styles.css              # 蓝黑黄主界面样式
├─ app.js                  # 目录、卡片与界面交互
├─ theme-editor.js         # 主题文字和颜色编辑演示
├─ gallery3d.js             # 壁纸插画 3D 浏览
├─ opening.js               # 开场视频与密集方格转场
├─ bgm.js                   # BGM 播放与控制台
├─ gallery3d/               # 十张内置壁纸插画
├─ offline/                 # 静态演示图片副本
├─ intro/                   # 开场视频与海报
└─ bgm/                     # 内置背景音乐
index.html                  # GitHub Pages 根入口
```

## 运行方式
直接打开在线地址即可浏览。

## 设计方向

- 赛尔档案馆作为唯一产品名称与界面语境。
- 蓝黑底色承载资料层级，荧光黄用于选中状态和操作提示。
- 面板、按钮和卡片采用圆角与半透明层，保留机能科技感并降低锐利感。
- 【壁纸插画】使用透视卡片浏览，其他分类保持平面资料卡布局。
